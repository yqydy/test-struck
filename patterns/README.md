# 参考实现与模式

这些文件不是框架，也不是生产级代码；它们是**可复制的结构**，帮你在项目里快速落地本 kit 的关键模式。每个文件都标注了生产化时必须补的部分。

| 文件 | 用途 |
|---|---|
| `react_agent.py` | 带工具、停止条件、错误反馈的 ReAct 骨架 |
| `rag_pipeline.py` | 有权限过滤、引用、无答案策略的 RAG 骨架 |
| `eval_runner.py` | 用 JSONL 评测集跑指标、阈值、回归门禁 |
| `eval_cases.sample.jsonl` | 8 条客服 Agent 评测样例 |
| `tool_contract.md` | 工具合同模板与审批矩阵 |
| `vertical_slice.md` | 一条纵向切片的拆解模板 |

原则：

- 先跑通最小闭环，再替换 mock。
- 所有外部输入（文档、网页、工具结果）都视为不可信数据。
- 评测集、trace、成本从第一天就记录。
- 参考代码不替代你的架构、权限、合规与安全评审。
