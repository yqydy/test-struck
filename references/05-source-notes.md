# 05 · 来源、许可与边界

## 来源

本 kit 是对以下三个公开仓库的**结构化提炼与项目化编排**，不是官方文档，也不代表原作者：

| 仓库 | 作者/组织 | 本 kit 使用重点 |
|---|---|---|
| [Easy-Vibe](https://github.com/datawhalechina/easy-vibe) | Datawhale China | 产品原型、全栈、上线、跨端、AI 原生工作流 |
| [Hello-Agents](https://github.com/datawhalechina/hello-agents) | Datawhale China | Agent 原理、ReAct、工具/MCP、记忆/RAG、上下文、评测 |
| [Awesome-Architecture](https://github.com/study8677/awesome-architecture) | study8677 | 架构判断、C4/ADR、分布式、失败、选型、模板/案例 |

数据整理与核对时间：**2026-11-06**。Star 数是当时量级：

- Easy-Vibe：20k+
- Hello-Agents：86k+
- Awesome-Architecture：2.5k

## 许可

- 上游来源的许可各自独立：
  - Easy-Vibe：CC BY-NC-SA 4.0
  - Hello-Agents：CC BY-NC-SA 4.0
  - Awesome-Architecture：MIT
- 本 kit 的原创编排、清单和模板以 **CC BY-NC-SA 4.0** 提供，要求署名、非商业、相同方式共享。
- 商业使用前请分别核对三个上游仓库的许可证；不要将本 kit 当作法律意见。

## 边界

- 上游 README 与目录比 GitHub 简介更新的情况可能存在（例如 Awesome-Architecture 简介与 README 的章节/模板数量不一致）；本 kit 以 README/目录的口径为主。
- 上游课程和 star 会变化；引用前请打开原仓库确认。
- 本 kit 提供的是**判断与流程**，不替代具体项目的代码、数据、法律、安全与合规评审。
- 任何“最佳实践”都必须结合当前规模、团队、成本、合规和失败后果重新判断。
